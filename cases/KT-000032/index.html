Case KT-000032

Proprietary Surveillance Export Failed in Its Playback Chain

Category: Evidence Handling / Application Dependencies

Status: Playback Chain Isolated / Safer Re-Export Path Recommended

Locked lesson

A proprietary file that will not play is not automatically corrupt. Prove the format, viewer, dependencies, package completeness, and endpoint behavior before changing the evidence.

Supporting principle

Preserve the source first. Troubleshoot the playback chain around it before modifying, converting, or replacing the original evidence.

Investigation path

Preserve source → Identify proprietary format → Test standard players → Test bundled viewer → Capture dependency errors → Test another endpoint → Isolate playback chain → Recommend standard re-export or complete supported player package

What the evidence showed

The surveillance export could not be decoded by normal media players. The bundled viewer launched but produced runtime or dependency errors and blank video. Testing the viewer from multiple locations and on another endpoint narrowed the relevant fault domain to the vendor playback chain.

Outcome

The strongest supported recommendation was to obtain a fresh export in a standard format or a complete current standalone-player package. The available record did not prove that the original export itself was corrupt.

Boundaries

This case does not claim that every proprietary export failure is a codec problem, that the source file was corrupt, or that installing third-party codec packs is an appropriate evidence-handling step. No identifying case, customer, camera, location, filename, timestamp, or evidentiary details are published.

KrippyTech Case KT-000021

BitLocker Recovery Key Was Missing from One Console but Present in Entra ID

A recently imaged endpoint entered BitLocker recovery, but the expected recovery-key field in the management platform was empty.

The empty field did not prove the key was unavailable. The recovery path depended on checking the correct device against another approved escrow source.

Category
Endpoint Security & Recovery
Status
Recovery Key Found / Boot Verified
Technologies
Windows / BitLocker / Microsoft Entra ID / Endpoint Management

Locked lesson

An empty recovery-key field in one console does not prove the key is gone. Verify the device and check every approved escrow source.

Know the escrow hierarchy before a recovery event forces you to discover it under pressure.

Investigation path

Recovery screen → Expected escrow source → Empty result → Device identity match → Alternate approved escrow → Key retrieval → Protected delivery → Successful boot → Escrow-gap review

What the evidence showed

The expected management-platform field did not contain the BitLocker recovery key. The endpoint was then located in Microsoft Entra ID, where the matching device record contained the recovery key. The key was retrieved from that approved source, delivered through a protected channel, and the user confirmed successful recovery.

What this case does not prove

  • It does not prove Entra ID is always the authoritative recovery-key source.
  • It does not prove a missing key in one console means another system will contain it.
  • It does not support retrieving or disclosing a recovery key without matching the correct device and confirming authorization.
  • It does not expose any real recovery key, device identifier, user identity, or screenshot.

Verification

  • Match the recovery-key identifier or device before retrieving a key.
  • Confirm the requester is authorized.
  • Retrieve only from an approved escrow source.
  • Deliver the key through an approved protected channel.
  • Verify successful boot.
  • Review why the expected secondary escrow source lacked the key.

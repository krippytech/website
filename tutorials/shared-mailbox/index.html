Microsoft 365 Tutorial

Create a Microsoft 365 Shared Mailbox

A practical walkthrough for creating a shared mailbox, assigning members, configuring access, and confirming everything works correctly.

Estimated Time: 10–15 minutes

Difficulty: Easy

Applies To: Microsoft 365, Exchange Online, Microsoft 365 Business, Enterprise, and Education tenants

Overview

A shared mailbox allows multiple users to read and send email from a common address such as support@company.com, accounting@company.com, or reception@company.com.

This guide explains how to create the mailbox, assign the required permissions, and verify that users can access it.

When to use a shared mailbox

Use a shared mailbox when several people need to work from one common email address without signing in as a separate user.

  • Customer support
  • Accounting or billing
  • Human resources
  • Reception or general inquiries
  • Sales teams

Prerequisites

  • Microsoft 365 administrator access
  • A display name for the shared mailbox
  • An available email address
  • A list of users who need access

Create the shared mailbox

Create the shared mailbox

  1. Sign in to the Microsoft 365 Admin Center.
  2. Select Teams & Groups → Shared mailboxes.
  3. Click Add a shared mailbox.
  4. Enter the mailbox display name.
  5. Enter the email address you want users to send from.
  6. Click Create.

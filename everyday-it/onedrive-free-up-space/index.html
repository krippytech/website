Everyday IT · OneDrive

Free disk space without deleting the user's files.

A huge OneDrive folder does not automatically mean every byte is physically stored on C:. Files On-Demand separates the cloud copy from the local cached copy.Verify sync health first. Use Free up space, not Delete.

Diagnose the spaceBack to SharePoint & OneDrive

Find out what is actually using the disk

Repeated Temp cleanup is not the answer when the user profile is the real storage consumer.

Step 1

Check free space

Confirm the current C: drive free capacity so you have a before-and-after measurement.

Step 2

Find the largest area

Compare top-level folders and the active user's profile folders. If C:\Users dominates, inspect the profile before spending more time on Windows component cleanup.

Step 3

Separate logical size from physical use

OneDrive placeholders can report their full logical file size even when the file is not fully stored locally. Compare Size with Size on disk and inspect OneDrive status icons.

Read the OneDrive status icons

The icon tells you whether a file is cloud-only, cached locally, pinned locally, or still synchronizing.

Blue cloud

Cloud-only

The item remains visible but uses minimal local disk space until opened.

Outlined green check

Locally available

The file has a local cached copy and consumes disk space. This local copy can generally be released with Free up space.

Solid green circle

Always available

The item is intentionally pinned to stay local. Review that setting before expecting the space to be released.

Blue arrows

Synchronizing

Wait for active synchronization to finish before making large local-availability changes.

Safe Free up space workflow

The source procedure succeeded because sync health was verified before changing thousands of local files.

01

Confirm OneDrive is healthy

Make sure the OneDrive client is running, reports Up to date, and has no unresolved sync errors.

02

Confirm Files On-Demand

Verify that Free up space is available on the organizational OneDrive folder or the intended subfolder.

03

Select Free up space

Right-click the intended OneDrive folder and choose Free up space. Allow Windows and OneDrive to process the property changes.

04

Let it finish

Large working sets can involve tens of thousands of items. Do not cancel the operation, exit OneDrive, sign out, or restart while active synchronization is still processing.

05

Validate

Confirm OneDrive returns to Up to date, released files show blue cloud icons, files are still visible, and C: free space increased.

What not to do

Disk pressure makes destructive shortcuts tempting.

Do not

Click Delete instead

Free up space releases a local cached copy. Delete is a different action and can remove synchronized content.

Do not

Assume folder Size equals disk use

OneDrive placeholder logic means a large logical total does not prove the same amount is physically allocated on C:.

Do not

Interrupt active sync

Finish synchronization before rebooting or closing OneDrive during a large release operation.

Free the local copy. Preserve the cloud copy.

When OneDrive is the storage consumer, supported Files On-Demand controls are safer than deleting user documents to create space.
